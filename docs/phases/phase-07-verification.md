# Phase 07 — Verification

## Includes

- Unit tests for routing, tools, memory, and approval.
- MCP in-memory tests for Attic tools.
- Valkey and Attic failure tests.
- WhatsApp and Telegram smoke tests.
- One ChatGPT/MCP integration test.

## Required scenarios

1. Store and recall a user preference.
2. Stop Attic and continue chatting.
3. Stop Valkey and continue chatting.
4. Run built-in commands without Groq.
5. Use one local tool.
6. Reject cross-user memory access.
7. Require approval for sensitive action.

## Exit gate

Critical workflows have runnable proof, not only documentation.
