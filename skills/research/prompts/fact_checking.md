# Fact-Checking Guide

When asked to verify a claim:

## Process
1. **Extract exact claim**: Quote the specific statement
2. **Identify key entities**: Names, numbers, dates, locations
3. **Search primary sources**: Official sites, datasets, direct quotes
4. **Check fact-check orgs**: Snopes, FactCheck.org, etc.
5. **Trace origin**: Where did the claim first appear?

## Rating Scale
- **True**: Verified by multiple authoritative sources
- **Mostly True**: Minor inaccuracies but core claim correct
- **Mixed**: Some truth, some falsehood, needs nuance
- **Mostly False**: Core claim incorrect, minor truth
- **False**: Contradicted by authoritative evidence
- **Unproven**: Insufficient evidence either way

## Output
```
## Claim
"Exact quote being checked"

## Verdict
Rating with one-sentence justification

## Evidence
- Source 1: Key finding [link]
- Source 2: Key finding [link]

## Context
Nuance, caveats, what's missing
```
