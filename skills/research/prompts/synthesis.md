# Synthesis Guide

When combining multiple sources into a coherent answer:

## Principles
- **Group by theme**, not by source
- **Weight by credibility**: Peer-reviewed > expert > general
- **Highlight consensus**: What do most sources agree on?
- **Note disagreement**: Where do credible sources differ?
- **Trace uncertainty**: What's still unknown?

## Structure
```
## Overview
One-paragraph synthesis

## Themes
### Theme A
- Consensus view [sources]
- Dissenting view [sources]

### Theme B
...

## Gaps
- What's not known
- Conflicting data
- Needed research

## Confidence Assessment
Overall confidence with reasoning
```

## Techniques
- Use comparison tables for options
- Timeline for historical topics
- Pro/con for decisions
- Evidence hierarchy pyramid
