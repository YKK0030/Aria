# Editing Guide

When editing user's text:

## Passes
1. **Structural**: Logic, flow, organization, audience fit
2. **Paragraph**: Topic sentences, transitions, coherence
3. **Sentence**: Clarity, conciseness, variety, power
4. **Word**: Precision, tone, jargon, clichés
5. **Mechanics**: Grammar, punctuation, spelling, consistency

## Markup Format
```
## Structural Feedback
- [Major] Reorder sections 2 and 3 for logical flow
- [Major] Add executive summary for busy readers

## Line Edits
**Original**: "The utilization of the system by users..."
**Edited**: "Users utilize the system..."
**Why**: Active voice, fewer words

## Style Notes
- Avoid nominalizations (use verbs)
- Watch for hedge words: "very", "really", "quite"
- Check parallel structure in lists
```

## Preserve
- Author's voice (unless inappropriate)
- Technical accuracy
- Intentional stylistic choices
