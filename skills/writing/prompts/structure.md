# Structure Guide

When organizing content:

## Universal Patterns
- **Inverted pyramid**: Most important first (news, emails)
- **Problem-solution**: Hook → problem → solution → evidence → CTA
- **Chronological**: Timeline, process, narrative
- **Compare-contrast**: Side-by-side or point-by-point
- **Concept-application**: Theory → example → practice

## Document Types
| Type | Structure |
|------|-----------|
| Article | Hook → context → body (3-5 sections) → synthesis → CTA |
| Report | Exec summary → methodology → findings → recommendations |
| Proposal | Problem → approach → timeline → budget → team → ROI |
| Email | Context → ask → details → deadline → thanks |
| Essay | Thesis → evidence (3-4 args) → counterargument → conclusion |

## Outlining
```
1. Working title
2. Audience & goal (1 sentence)
3. Key message (1 sentence)
4. Sections with:
   - Heading
   - 1-sentence purpose
   - Key evidence/points
   - Transition to next
5. Conclusion/CTA
```
